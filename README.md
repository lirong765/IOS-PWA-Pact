# 契约 Pact — 项目说明

## 项目简介

**契约**是一款自奖励目标打卡 PWA 应用。设定目标，绑定真实奖励（带照片），在期限内完成打卡才能解锁奖励。AI 教练通过数据分析帮助用户守住和自己的约定。

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | HTML5 + CSS3 + 原生 JavaScript（ES6+） |
| 图标 | 内联 SVG（无外部依赖） |
| 架构 | PWA（Progressive Web App），支持离线使用 |
| 存储 | localStorage（浏览器本地），数据不外传 |
| AI | Claude API（用户自带 Key） |
| 平台 | iOS Safari / Mac 浏览器，"添加到主屏幕"全屏运行 |

## 项目结构

```
契约App/
├── index.html         — 主页面（HTML + CSS + 内联 SVG 图标）
├── app.js             — 应用逻辑（状态管理、渲染、AI 教练）
├── manifest.json      — PWA 配置文件
├── sw.js              — Service Worker（离线缓存）
└── README.md          — 项目说明（本文件）
```

## 核心功能

### 目标 & 奖励设定
- 设定目标名称、打卡天数、有效期限
- 填写奖励描述 + 上传奖励照片
- 照片上传无大小限制，自动压缩至 ≤300KB
- 选择失败规则（严格/宽容/阶梯三种模式）
- 点击"立下契约"即生效

### 照片管理
- 创建时上传照片，支持拍照/相册选取
- 契约详情页支持 🔄 更换照片 和 移除照片
- 照片以 base64 存储在 localStorage 中
- 仪表盘目标卡片显示照片缩略图（48px）
- 详情页显示大图（240px）
- 奖励陈列馆中也展示真实照片

### 双进度条系统
- **打卡进度**：已完成天数 / 目标天数
- **时间消耗**：已过天数 / 期限天数
- 对比公式：`gap = 打卡进度% - 时间消耗%`
  - gap ≥ +10% → 进展领先 ✅
  - -10% < gap < +10% → 节奏正常 ➖
  - gap ≤ -10% → 进度落后 ⚠️

### 期限紧迫度
- 🟢 safe（安全）：时间充足
- 🟡 tight（紧迫）：时间不够或临近
- 🔴 over（过期）：已超期

### 三段式分类
- 进行中 | 已完成 | 已过期
- 分段控件切换，各自显示数量

### 奖励陈列馆
- ✅ 已解锁区（正常展示奖励照片）
- 🔒 进行中区（锁定遮罩 + 进度%）
- ❌ 已过期区（灰度失效 + 完成度）

### 契约管理
- 所有状态契约均可删除（带确认弹框）
- 删除时自动清理关联的打卡记录

### AI 教练
- 透明的数据分析：展示完整计算过程
- 场景感知回复：具体目标分析、疲惫鼓励、失败复盘、进步回顾、奖励查询
- 首次打开自动生成含数据问候
- 今日打卡状态横幅

### 数据备份
- ⚙️ 仪表盘右上角设置按钮
- 📤 导出备份：生成 JSON 文件下载到本地
- 📥 导入恢复：选备份文件合并恢复（不会覆盖不重复的数据）
- 备份包含：所有目标、打卡记录、照片

### 版本更新
- 部署新版本后，Service Worker 自动检测更新
- 手机端底部弹出「🔄 新版本可用」横幅
- 点击「立即更新」→ 页面自动刷新加载最新版
- 备份面板底部显示当前版本号

## 数据存储

| 数据 | Key | 格式 |
|------|-----|------|
| 目标列表 | `pact_goals` | JSON 数组（含 base64 照片） |
| 打卡记录 | `pact_checkins` | `{ "日期_目标ID": true }` |
| 备份 | 导出为 `pact_backup_日期.json` | JSON |

## 如何部署

### 本地开发
```bash
cd 契约App
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

### 部署到 iPhone
1. 将文件夹部署到任意外网可访问的静态服务器（如 Netlify / GitHub Pages）
2. iPhone Safari 打开 HTTPS 地址
3. 分享 → "添加到主屏幕"
4. 桌面出现图标，点击全屏运行，体验等同原生 App

## AI 教练配置
